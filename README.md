# Estudos e Exercícios em C

Repositório dedicado aos meus estudos de linguagem C, reunindo exercícios e pequenos projetos desenvolvidos durante meu aprendizado em programação.

## Conteúdos praticados

- Lógica de programação
- Algoritmos
- Variáveis e tipos de dados
- Operadores
- Estruturas condicionais
- Estruturas de repetição
- Resolução de problemas

## Organização

Os exercícios estão organizados em pastas, conforme o desenvolvimento dos estudos.

## Tecnologia utilizada

- Linguagem C

## Objetivo

Praticar os fundamentos da programação, desenvolver o raciocínio lógico e fortalecer minha base em algoritmos.
